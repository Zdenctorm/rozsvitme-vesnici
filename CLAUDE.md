# Adventní okénka

Mobile-first web: a night map of Czechia showing which houses light up their advent window tonight, with navigation to them. Villages and towns register their own living advent calendar. Launch 20 Nov 2026, live 1 to 24 Dec.

Product decisions, research and history live in the owner's vault, `zdenctorm/zdenal-vault`, folder `1-Projects/rozsvitme-vesnici/`. This repo is driven from there.

## Quality bar, non-negotiable

The owner rejects anything that looks cheap or AI-generated. Before any UI or copy work, read `docs/quality-bar.md`. In short:

- **Design:** load the `impeccable` skill before any UI edit. Every UI change ends with `impeccable critique` and `impeccable audit` on screenshots at 390 px wide.
- **Czech copy:** every user-facing Czech string passes the `anti-ai-slop-cz` skill. No parentheses, no long dashes.
- **Approval:** the visual direction is chosen by the owner from rendered variants before features are built on it.
